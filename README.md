# нео — AI-дайджест для новичков

## О сайте

«нео» — короткий AI-дайджест для тех, кто только знакомится с нейросетями. Он помогает сделать первый шаг без сложных терминов: выбрать тему, прочитать небольшой материал и попробовать идею самостоятельно.

На сайте собраны девять карточек о ChatGPT, Codex, составлении промптов, выборе инструментов, проверке ответов AI и создании первого проекта. В каждой карточке есть примерное время чтения. Кнопка «Открыть материал» показывает статью в отдельном окне, а в конце предлагает следующий небольшой шаг.

## Возможности

- Фильтрация карточек по темам: старт, промпты, код и проекты, ошибки.
- Полные тексты материалов в диалоговом окне.
- Адаптивная сетка для компьютера и телефона.
- Тёмный интерфейс, цветовые акценты и плавные анимации.
- Инструкция по запуску на Flask без дополнительной настройки.

Сайт не требует регистрации и не сохраняет пользовательские данные. Материалы — встроенный контент проекта.

## Запуск

1. Установи Python 3.9 или новее.
2. Открой терминал в папке проекта.
3. Установи Flask: `python -m pip install -r requirements.txt`
4. Запусти сайт: `python app.py`
5. Открой в браузере адрес `http://127.0.0.1:5000`.

## Где что находится

- `app.py` — Flask-приложение и список карточек с текстами материалов.
- `templates/index.html` — HTML-разметка главной страницы.
- `static/css/style.css` — цвета, карточки, анимации и адаптация под телефон.
- `static/js/main.js` — фильтры карточек и окна с материалами.
- `requirements.txt` — зависимость Flask.

Чтобы добавить материал, дополни список `MATERIALS` в `app.py`. Для фильтрации укажи темы в поле `tags`.
